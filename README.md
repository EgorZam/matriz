# Матрица Эйзенхауэра — настоящая Windows Desktop версия

Это тот же интерфейс матрицы, но упакованный как настоящее Windows-приложение через Tauri 2.

Пользователь получает установщик `*-setup.exe`, устанавливает приложение и запускает его обычным ярлыком.

## Для пользователя

После установки:

1. На рабочем столе появляется «Матрица Эйзенхауэра».
2. Запускаем двойным кликом.
3. Не открываются вкладки и адресная строка браузера.
4. LocalStorage / IndexedDB хранят данные локально в профиле WebView приложения.
5. Интернет для работы матрицы не нужен.

## Вариант A — собрать .exe на Windows

Нужны Node.js LTS, Rust и инструменты Visual Studio C++ Build Tools. Tauri использует Microsoft Edge WebView2 для отрисовки интерфейса Windows-приложения.

После установки зависимостей:

```powershell
npm install
npm run tauri build
```

или двойной клик по `build-windows.bat`.

Готовый установщик:

`src-tauri/target/release/bundle/nsis/Матрица Эйзенхауэра_1.0.0_x64-setup.exe`

## Вариант B — без установки Rust и Visual Studio

Загрузите проект в GitHub и запустите:

`Actions → Build Windows app → Run workflow`

GitHub Actions соберёт Windows installer на виртуальной Windows-машине и отдаст `.exe` как Artifact.

## Важно про данные

Приложение не использует localhost, внешний сервер или аккаунт. Данные хранятся локально. Перед переустановкой рекомендуется экспортировать резервную копию JSON из меню приложения.

## WebView2

Tauri использует Microsoft WebView2. На Windows 11 он поставляется вместе с системой; на актуальных Windows 10 WebView2 также распространяется с системой. Инсталлятор Tauri умеет установить/обновить runtime при необходимости.
